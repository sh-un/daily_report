### 型（Types）の概要
- 型は、扱える値と、その値に対する操作やメソッドを定める
  - 例）`var n int = 1 + 2`
- 型は「型名」か「型リテラル」で表す
  - 例）`int`（型名）/ `[]int`（型リテラル）
- 型名には、事前宣言されたものと、`type` で宣言するものがある
  - 例）`string` / `type User struct{}`
- 型リテラルは、既存の型を使って型の構造を直接書いたもの
  - 例）`*string` / `[]int` / `map[string]int` / `struct{ n int }`
- 型リテラルで表す型を「複合型」と呼び、ポインタ・スライス・マップ・構造体・配列・関数・インターフェース・チャネルの 8 つがある
  - 例）`*string`（ポインタ）/ `[3]int`（配列）/ `struct{ n int }`（構造体）/ `interface{ String() string }`（インターフェース）
- `type` で定義した型は、元の型とは別の型になる
  - 例）`type Age int` → `Age`（年齢）と `int` は別の型

### 型の種類（全 11 種類）
| 型の種類 | 日本語名 | 型の例 | 特徴 |
|---|---|---|---|
| Boolean types | 真偽値型 | `bool` | true または false のいずれかを表す |
| Numeric types | 数値型 | `int`, `float64` | 数値を表す。異なる数値型同士の計算には型変換が必要 |
| String types | 文字列型 | `string` | 文字列を表す。文字列を表す。文字列の値はバイト列として扱われる |
| Array types | 配列型 | `[3]int` | 同じ型の値を固定長で並べる。長さは変更できない |
| Slice types | スライス型 | `[]int` | 同じ型の値を可変長で並べる。実務では配列よりこちらを多用する |
| Struct types | 構造体型 | `struct{...}` | 任意の型の値を、名前付きのフィールドとして複数まとめる |
| Pointer types | ポインタ型 | `*string` | 値そのものではなく、値の格納場所（アドレス）を保持する |
| Function types | 関数型 | `func(int) error` | 関数を値として扱うための型。変数への代入や引数での受け渡しができる |
| Interface types | インターフェース型 | `interface{...}` | 必要なメソッドを定め、それを満たす任意の型の値を格納できる |
| Map types | マップ型 | `map[string]int` | キーを指定して値を取り出す、キーと値の組の集合 |
| Channel types | チャネル型 | `chan int` | goroutine 間で値を送受信する |

## 感じたこと
- `type 型名 struct{...}` や `type 型名 interface{...}` は特別な構文だと思っていたが、実際は `type 型名 型` という型宣言の 1 つのルールで、`struct{...}` や `interface{...}` も `*string` と同じ型リテラルの一種だとわかった
- Go の型は 11 種類あり、それぞれ役割が決まっている。変数や引数がどの種類の型かを意識すれば、その値で何ができるか（値を並べる、まとめる、指し示す、受け渡すなど）が判断でき、コードを読み書きしやすくなると感じた

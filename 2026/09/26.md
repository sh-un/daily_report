## わかったこと
- ポインタ
  - 変数のメモリ上の場所（アドレス）を表す値。`&変数名` で取得できる
- ポインタ型
  - ポインタを入れるための型。`*型名` で表し、どの型にも作れる（例：`*string`、`*int`など）
- ポインタ型変数
  - ポインタ型で宣言された変数。アドレスを値として持つ。宣言や代入の方法は他の型の変数と同じ（例：`namePtr` など）
- ポインタの間接参照（デリファレンス）
  - ポインタ型変数を `*変数名` とすることで、ポインタの参照先の値を読み書きすること（例：`*namePtr` など）

- 文字列型（string）変数とポインタ型（*string）変数宣言・初期化の比較
  ```go
  // 文字列型（string）の変数宣言・初期化
  var name string = "John"
  // または
  name := "John"

  // ポインタ型（*string）の変数宣言・初期化（name のアドレスを持つ）
  var namePtr *string = &name
  // または
  namePtr := &name
  ```

- 文字列型（string）の変数の例：`name`
  | 書き方 | 意味 | 結果 |
  |---|---|---|
  | `name` | `name` の値 | `"John"` |
  | `&name` | `name` のアドレス | `0xc000014070` |
  | `*name` | 値をアドレスとしてたどる | エラー（値がアドレスではない） |

- ポインタ型（*string）の変数の例：`namePtr`
  | 書き方 | 意味 | 結果 |
  |---|---|---|
  | `namePtr` | `namePtr` の値（`name` のアドレス） | `0xc000014070` |
  | `&namePtr` | `namePtr` 自身のアドレス | `0xc00000e028` |
  | `*namePtr` | アドレスをたどった先（`name` の値） | `"John"` |

- 値渡し
  - Go の引数は値渡し（コピーが渡される）。
  - 別の関数から変数の値を書き換えるには、
    - 関数へ文字列型（string）変数（`name`）へのポインタ（`&name`）を渡し、
    - 関数側ではポインタ型（*string）の引数（`namePtr`）で受け取り `*namePtr` に値を代入する

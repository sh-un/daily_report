## わかったこと
- Delve とは
  - https://github.com/go-delve/delve
  - Delve は Go 言語用のデバッガ
  - CLI からブレークポイントの設定、変数確認、ステップ実行などができる
  - VS Code の Go デバッグでも内部的に Delve が利用されている

- インストール手順
  ```bash
  # インストール
  go install -v github.com/go-delve/delve/cmd/dlv@latest

  # 環境変数設定（.zshrc / .bashrc 等に設定）
  export PATH="$PATH:$(go env GOPATH)/bin"

  # バージョン確認
  dlv version
  ```

- 使い方
  ```go
  // main.go
  package main

  import "fmt"

  func main() {
      m := "Hello, World"
      fmt.Println(m)
  }
  ```

  ```bash
  dlv debug main.go
  (dlv)
  ```

- 主なコマンド
  - `b <関数名 または ファイル名:行番号>`：ブレークポイントを設定
    - 例：`b main.main`
    - 例：`b main.go:10`
  - `c`：次のブレークポイントまで実行
  - `n`：次の行へ進む（関数の中には入らない）
  - `s`：次の行へ進む（関数呼び出しの場合は中に入る）
  - `p <変数名>`：変数の値を確認（例：`p message`）
  - `locals`：現在の関数内のローカル変数を一覧表示

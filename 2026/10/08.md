### Go のゼロ値
- 明示的な初期化をしなかった場合に、変数に割り当てられるデフォルト値のこと

### ゼロ値が nil ではない型
| 型の種類 | 日本語名 | 型の例 | ゼロ値 |
|---|---|---|---|
| Boolean types | 真偽値型 | `bool` | `false` |
| Numeric types | 数値型 | `int`, `float64` | `0` |
| String types | 文字列型 | `string` | `""` |
| Array types | 配列型 | `[3]int` | 各要素がその型のゼロ値（例: `[0 0 0]`） |
| Struct types | 構造体型 | `struct{...}` | 各フィールドがその型のゼロ値 |

### ゼロ値が nil の型
| 型の種類 | 日本語名 | 型の例 | ゼロ値 |
|---|---|---|---|
| Slice types | スライス型 | `[]int` | `nil` |
| Pointer types | ポインタ型 | `*string` | `nil` |
| Function types | 関数型 | `func(int) error` | `nil` |
| Interface types | インターフェース型 | `interface{...}` | `nil` |
| Map types | マップ型 | `map[string]int` | `nil` |
| Channel types | チャネル型 | `chan int` | `nil` |

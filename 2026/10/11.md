### 複合リテラル（Composite Literals）
- `型{...}` の形式で、値を初期化する式。
- 配列型・構造体型・スライス型・マップ型の4種類で使用できる（型パラメータには別途条件がある）。
- 型を表す部分には、型名または型リテラルを使用できる。

### 複合リテラルの種類（全4種類）
| 型の種類 | 日本語名 | 複合リテラルの例 | 説明 |
|---|---|---|---|
| Array types | 配列型 | `[3]int{1, 2, 3}` | 長さ3の配列を初期化 |
| Struct types | 構造体型 | `Point{X: 10}` | `Point` 型の構造体を初期化※ `Point` は定義済みの構造体型 |
| Slice types | スライス型 | `[]int{1, 2, 3}` | `int` 型のスライスを初期化 |
| Map types | マップ型 | `map[string]int{"a": 1}` | `string` 型のキーと `int` 型の値を持つマップを初期化 |

### 複合リテラルにおける名前付き型と無名型
- 名前付き型（Named type）：`type` で定義した型名を使って初期化する。
- 無名型（Unnamed type）：型名を持たず、型リテラルを直接使って初期化する。

| 型の種類 | 日本語名 | 複合リテラルの例 | 説明 |
|---|---|---|---|
| Named type | 名前付き型 | `Object{"edge", "black"}` | `Object` という型名を使って初期化 |
| Unnamed type | 無名型 | `struct{ name, color string }{"edge", "black"}` | 型リテラルを直接使って初期化 |

### コード例
- ①は、型名 `Object` に `{...}` を付けて初期化する。
- ②は、型リテラル `struct{...}` に `{...}` を付けて初期化する。
- ②では最初の `{...}` が型の構成、次の `{...}` が初期値を表すため、波括弧が2組になる。

  ```go
  // ① 名前付き構造体型
  type Object struct { name, color string }
  a := Object{"edge", "black"}

  // ② 無名構造体型
  b := struct{ name, color string }{"edge", "black"}
  ```

### 型リテラルとの違い
| 用語 | 日本語名 | 役割 | 例 |
|---|---|---|---|
| Type literal | 型リテラル | 型の構成を記述する | `struct{ X int }` |
| Composite literal | 複合リテラル | 値を初期化する | `struct{ X int }{X: 10}` |

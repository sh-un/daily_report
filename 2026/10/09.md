### Go のエラー型
- 関数が失敗したかどうかと、その理由を呼び出し元に返すための型
- `Error() string` メソッドを 1 つだけ持つ、あらかじめ宣言されたインターフェース型
- `nil` は「エラーなし」を表す（インターフェース型なのでゼロ値も `nil`）
- Go には例外がなく、通常の戻り値と一緒に `error` を返して、呼び出し元で `if err != nil` でチェックする
- エラー型の定義
  ```go
  type error interface {
    Error() string
  }
  ```
- 使用例
  ```go
  // os.Open のシグネチャ: func Open(name string) (*File, error)
  f, err := os.Open("filename.ext")
  if err != nil {
      log.Fatal(err)
  }
  // do something with the open *File f
  ```

## 感じたこと
- Errors are values.
  - エラーは値である
- Go は、ファイルが開けないような普通のエラーを「例外」ではなく通常の戻り値として扱う設計になっている
- try-catch のように制御構文と結びつけず、エラーを戻り値で受け取ってその場で確認するため、どこでエラーを処理しているかがコード上で明確になる

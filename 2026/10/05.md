- インターフェースの暗黙的な実装（Go）
  - Go では、インターフェースに定義されたメソッドをすべて持つ型は、そのインターフェースを暗黙的に実装したことになる。
  - 型が持つメソッドの集合を「メソッドセット（Method Set）」と呼び、インターフェースの実装にはメソッド名とシグネチャ（引数・戻り値の型など）の一致が必要。
  - Java の `implements` のような明示的な実装宣言は不要。また、Go には型継承がないため、継承関係を定義する必要もない。
    ```go
    type Animal interface {
        Sound() string // インターフェースのメソッドセット
    }

    // implements Animal などの宣言は不要
    type Dog struct {
        Name string
    }

    // Animal とメソッド名・シグネチャが一致
    // インターフェースを暗黙的に実装
    func (d Dog) Sound() string {
        return "ヨン！"
    }

    var animal Animal = Dog{Name: "４と鳴く犬"}
    ```

- インターフェースの明示的な実装（Java）
  - Java では、必要なメソッドを定義するだけでなく、`implements` を使ってインターフェースの実装を明示的に宣言する必要がある。
    ```java
    interface Animal {
        String sound();
    }

    // インターフェースを明示的に実装
    class Dog implements Animal {
        String name;

        Dog(String name) {
            this.name = name;
        }

        public String sound() {
            return "ヨン！";
        }
    }

    // Dog のインスタンスを作成し、Animal 型の変数に代入
    Animal animal = new Dog("４と鳴く犬");
    ```

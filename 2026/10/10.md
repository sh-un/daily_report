### 複合型（Composite Types）
- 型リテラル（Type Literal）を用いて構成できる8種類の型のこと
- 型リテラルとは、型全体に名前をつけずに、型の構成を直接記述する構文
  - 型リテラルの例：
    - `[]int`
      - 要素型が int のスライス型を表す型リテラル
    - `*int`
      - 基底型が int のポインタ型を表す型リテラル
    - `struct{ X int }`
      - int 型のフィールド X を持つ構造体型を表す型リテラル
- リテラルとは、数値や文字列などの値を直接記述する構文
  - リテラルの例：
    - `3`
      - 整数を表すリテラル
    - `"Hello"`
      - 文字列を表すリテラル

### 複合型の種類（全8種類）
| 型の種類 | 日本語名 | 型の例 | 特徴 |
|---|---|---|---|
| Array types | 配列型 | `[3]int` | 同じ型の値を固定長で並べる |
| Struct types | 構造体型 | `struct{ X int }` | 異なる型の値を名前付きフィールドとしてまとめる |
| Pointer types | ポインタ型 | `*int` | 変数のアドレスを保持する |
| Function types | 関数型 | `func(int) int` | 関数の引数と戻り値の型を定義する |
| Interface types | インターフェース型 | `interface{ Read() }` | 型が満たすべき条件を定義する |
| Slice types | スライス型 | `[]int` | 同じ型の値を可変長で扱う |
| Map types | マップ型 | `map[string]int` | キーと値の組を管理する |
| Channel types | チャネル型 | `chan int` | goroutine 間で値を送受信する |

### コード例（各複合型の値の初期化）

  ```go
  // 配列型
  a := [3]int{1, 2, 3}

  // 構造体型
  s := struct{ X int }{X: 10}

  // ポインタ型
  p := new(int)

  // 関数型
  f := func(x int) int { return x }

  // インターフェース型
  var i interface{} = 10

  // スライス型
  sl := []int{1, 2, 3}

  // マップ型
  m := map[string]int{"a": 1}

  // チャネル型
  ch := make(chan int)
  ```

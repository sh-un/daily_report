### 複合リテラルのアドレス取得（addressable の例外）
- アドレス演算子 `&` は、変数などのアドレス取得可能（addressable）な式に使用する
- 例外として複合リテラルには直接 `&` を付けられる
- `&型{...}` と書くと複合リテラルで初期化された変数へのポインタを取得できる（名前付き変数の宣言を省略できる）

### コード例
```go
// 変数を宣言してからポインタを取得
f := File{fd, name, nil, 0}
return &f

// 複合リテラルから直接ポインタを取得
return &File{fd, name, nil, 0}
```

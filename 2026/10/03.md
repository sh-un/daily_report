## わかったこと
- Go のコンストラクタ（慣習）
  - Go にはクラスやコンストラクタ構文がないため、`NewXxx()` という命名の関数を用いて構造体を初期化する慣習がある。
  - コンストラクタとは、インスタンスを作るときに、初期値の設定などの初期化処理を行う仕組みのこと。
    - Python の `__init__()` や Ruby の `initialize()` がこれにあたり、受け取った引数でフィールドに値を設定するのに使われる。
  - [Effective Go](https://go.dev/doc/effective_go#composite_literals) では、ゼロ値のままでは不十分な場合にコンストラクタを用意するとされている。
    - 例えば `name` を非公開（小文字始まり）にすると、外部からは `User{name: "Taro"}` で値を入れられないため、`NewUser()` を通して設定する。
  - `NewXxx()` は普通の関数なので、呼ぶかどうかは使う側に任されている（Python の `User()` や Ruby の `User.new` は、必ず初期化処理が実行される）。

- コンストラクタの例
  - Python：`User()` で `__init__()` が必ず実行される
    ```python
    class User:
        def __init__(self, name):
            self.name = name

    u = User("Taro")
    ```

  - Go：非公開フィールド `name` は、`NewUser()` を通して設定する
    ```go
    package user

    type User struct {
        name string // 小文字始まりなので非公開
    }

    func NewUser(name string) *User {
        return &User{name: name}
    }
    ```

    ```go
    // 外部（別パッケージ）から使う場合
    u := user.NewUser("Taro")     // OK
    u2 := user.User{name: "Taro"} // コンパイルエラー（name は非公開）
    u3 := user.User{}             // NewUser を通さずにも作れる（name は空のまま）
    ```
